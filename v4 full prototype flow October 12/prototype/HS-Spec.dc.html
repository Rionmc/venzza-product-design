Header & search

Centred navigation with a search takeover

The approved header: 24px lockup on the left, navigation in the true centre, and search tucked into an icon. Opening search swaps the navigation for a field and suggestions, so nothing on the page shifts.

Lockup · 24pxGray V, white wordmark. Links to Home; the V turns lime on Home.
Navigation · true centreThree-column grid (1fr · auto · 1fr), so the nav stays centred whatever the sides contain.
Search trigger · 38pxIcon in a field-style pill so it still reads as search. Tooltip: Search · ⌘K.
NotificationsUnchanged: bell with the 8px lime dot.
AccountName truncates at 140px so the right column never grows into the nav.

Keyboard

⌘K / Ctrl KOpen search from any screen
↑ ↓Move through suggestions and results
EnterOpen the highlighted item, or “See all results”
EscClose and return focus to the search icon

Content rules

  • Searches your campaigns, your projects, and marketplace creators and organizers.
  • Groups in the order Campaigns, Projects, Marketplace; up to 3 each in the panel. Creator-only accounts don’t see Campaigns; sponsor-only accounts don’t see Projects.
  • Empty field shows 3 recent searches and 3 recently viewed items; first-time users see example searches.
  • “See all results” opens the full Search page with type filters.
  • The query is kept if search is closed, and cleared after opening a result.

Accessibility & sizes

  • Field is a combobox with a listbox of options; the result count is announced politely.
  • Navigation is hidden from screen readers while search is open.
  • ≥ 1300px: everything visible. 1000–1300px: the account name hides while search is open. < 1000px: the grid relaxes and the field fills the centre.
  • Lime stays reserved for the notification dot, the Home V and the system focus ring.
