Who gets which notifications

Some accounts only create projects, some only sponsor through campaigns, and some do both. The notification system is the same for all three. What changes is which events arrive and how much context each row needs.

Creator

Owns projects. Notifications are about sponsors reacting to a project and its packages.

Needs action
  • Offer or counter-offer on a package
  • Offer expiring in 2 days or less
Updates
  • Offer approved, next step is the agreement
  • Saved to a wishlist, grouped when several sponsors do it
  • Ready to publish when setup is complete

Sponsor

Runs campaigns. Notifications are about creators answering offers and new projects that fit a brief.

Needs action
  • Creator replied with a counter-offer
  • Your offer is expiring without a reply
Updates
  • New matches for a campaign
  • A wishlisted project changed, e.g. a new package
  • Offer declined, with similar creators to try

Both

Has projects and campaigns. Gets both sets of events in one list, so every row has to say which side it's about.

What's added
  • A Creator or Sponsor tag on every row, next to the project or campaign name
  • As creator / As sponsor filter on the Notifications page
  • Home shows both panels; the attention strip mixes both, most urgent first
