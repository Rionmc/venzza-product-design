Colour roles

Colour carries meaning, so each colour has one job.

  • Lime is for actions only: the one primary button, focus, the current tab.
  • Green means complete or approved.
  • Mood colours set atmosphere: mood dots and the onboarding glow. Never on buttons.
  • Package colours identify a package everywhere it appears.
  • No lime in the glow. The glow uses mood or neutral colours.

Building a new screen

Start from the closest template in the design system.

  • Templates first: Project detail, Campaign board, Deal flow, Edit project, Packages, Edit campaign, and both onboardings.
  • Components, not copies. If something is missing, propose it for the design system before styling it locally.
  • Radius scale only: xs 2 sm 4 md 8 lg 12 xl 16 pill.
  • Edit actions use the secondary button. One primary action per view.
  • Check light mode on the Light mode page before calling a screen done. Use theme tokens, never fixed dark colours.

Behaviour

Keep these consistent across every flow.

  • Editors autosave. “Saving…”, then “All changes saved”.
  • Esc closes panels and viewers. Focus returns to where it came from.
  • The action dock appears only after a selection.
  • The media viewer has no actions: view, swipe, close.
  • Copies are never published automatically.
