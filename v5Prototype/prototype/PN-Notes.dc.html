Projects · edit & publish flow · design rationale

One workspace to edit the whole project

Edit mode used to be one long page of ten collapsible sections, and a single sponsorship package was spread over four of them. This workspace gives each section its own focused screen, and turns packages into things you open, edit and close, with a comparison view that matches exactly what sponsors see.

Principles

One package, one placeName, what’s included, price and availability live in one panel. You never hunt for the same package in another section.
Two views of the same dataCards for working on one package, Compare for balancing all of them. Both edit the same packages, so nothing gets out of sync.
Edit what sponsors readCompare uses the same rows and order as the sponsor’s comparison table, so the creator is shaping the buyer’s decision directly.
Saves itself, publishes onceEvery change saves automatically. “Review & publish” opens the full project page with changed sections marked, and you publish from there.

How it works for the whole project

Workspace layout

  • Top bar: full width and raised, with centred navigation and an avatar-only account.
  • Rail: project name and status, project strength, and sections grouped as About, Audience, Offer and Media & contact. Each shows complete, needs attention or not started. It collapses to icons at smaller widths.
  • Action bar: where you are, save status, Sponsor preview and Review & publish, always in the same place.
  • Overview: the new landing page for edit mode, with strength, what’s left before publishing, and a card per section.

Four section types

  • Forms (basics, dates, press quote, contact): short, with tips beside them and a live preview where it helps.
  • Lists (highlights, reach channels): add, edit in place, reorder; capped where quality matters (5 highlights).
  • Media (gallery): a drop zone that explains why it matters, then a grid with a cover image.
  • Complex (packages): Cards, Compare, the package editor and the deliverables library.

Package editor

  • Opens full screen (56px margin) for both new and existing packages: one centred form with numbered sections, and the live sponsor card on the right.
  • Three numbered steps (details, what’s included, price & payment) that tick off as you complete them.
  • Previous / next arrows move between packages without closing. Readiness fixes like “Add price” open straight on the right step.
  • The deliverables library stays a side panel from Compare or “Manage”: the place to review the whole list, and the only place to delete a deliverable.
  • A live card on the right shows what sponsors will see as you type.
  • One deliverable form everywhere. Add a new deliverable, or edit an existing one with the pencil on its row, using the same fields as the library. Edits note how many packages they affect and apply to all of them.
  • Creating a package says what’s still missing; editing saves as you go. Delete has an Undo.

Open questions

  • Editing a package after it’s been sold: lock contents and price, or create a new version for future buyers?
  • Currency per project or per package?
  • Drag to reorder packages (the menu has Move earlier and later for now).
  • Mobile: rail becomes a section picker; Compare scrolls with the first column pinned.
